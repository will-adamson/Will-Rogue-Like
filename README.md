## Project description and purpose
This project has been centered on the Unity UI toolkit and my ability to use it to implement a minimap.

For this project I used USS, UXML and C#. No extra dependecies will be needed in order to get this project to run. You can simply clone the repo and open Will-Rogue-Like\unity-project\Builds from there you will find Rogue-Like.exe, run that.
